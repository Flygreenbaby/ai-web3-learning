# Prompt 模板速查

> 来自 Day 3 学习笔记，每个模板配一句话核心总结。

---

## Instruction 结构类

### 四段式 Instruction 框架
> 用 [任务目标]/[可用输入]/[禁止行为]/[输出格式] 四段把需求写成可执行协议。

### Few-shot 示例模板
> 用正反示例教模型识别风险边界（低风险 auto / 高风险需人工确认）。

---

## 输出约束类

### Structured Output Schema
> JSON schema 用 enum 类型 + 嵌套结构把输出约束成机器可解析的固定字段。

### 四段式复习笔记模板
> 将任意学习文档改写为 summary/key_points/questions/analogy/Template 五个字段的结构化笔记。

---

## Context 工程类

### Context 稳定结构
> 把模型上下文分成 9 个分区（用户问题/任务状态/工具结果/可信来源等），防止信息混杂。

### 信息来源分级表
> 按可信度四级标注每类信息的处理方式（系统配置→直接信任，外部网页→隔离处理）。

### Memory 风险检查清单
> 5 条 ✅ 安全规则 + 3 条 ❌ 禁止项，确保跨会话记忆可撤销、不越权。

---

## 实操指令类

### 模型切换指令
> 指定 baseurl + model + api-key 三要素切换 Hermes 底层模型。

### README 迭代编辑指令
> 用禁止项 + 输出格式约束来控制 Agent 的文件编辑范围。
