## 4. 滑点与手续费分析

```
┌─ 价格分析 ──────────────────────────────────────────┐
│                                                      │
│  预期价格:    1 ETH = 2,500 USDC                     │
│  实际成交:    1 ETH = 2,487.63 USDC                  │
│  滑点:        -12.37 USDC（-0.49%）                  │
│                                                      │
│  手续费:                                              │
│  ├── Uniswap LP Fee:  0.3% = 7.5 USDC               │
│  ├── Gas Fee:         0.00381 ETH ≈ 9.53 USDC       │
│  └── 总成本:          ≈ 17.03 USDC（0.68%）          │
│                                                      │
│  用户实际收到:  2,487.63 USDC                        │
│  名义价值:      2,500.00 USDC                        │
│  实际损失:      12.37 USDC（滑点）                    │
│                                                      │
└──────────────────────────────────────────────────────┘
```

**滑点原因：**
- 池子流动性深度：约 $1.2 亿（足够深，滑点小）
- 交易金额 1 ETH 相对池子很小，所以滑点仅 0.49%
- 如果交易 100 ETH，滑点会显著增大

## 5. Agent 执行限制设计

如果让 AI Agent 执行同类 swap，必须设置以下限制：

```
┌─ Agent Swap 策略 ───────────────────────────────────┐
│                                                      │
│  🟢 自动执行条件（全部满足才执行）：                  │
│  ├── 滑点上限:          ≤ 1%                         │
│  ├── 单笔最大交易额:    ≤ 0.5 ETH                    │
│  ├── 协议白名单:        仅 Uniswap V2/V3 Router      │
│  ├── Token 白名单:      ETH, USDC, USDT, DAI         │
│  ├── 每日累计上限:      ≤ 2 ETH                      │
│  └── 池子深度检查:      TVL > $10M 才执行            │
│                                                      │
│  🔴 禁止执行：                                       │
│  ├── 不在白名单的 Token                              │
│  ├── 不在白名单的 DEX/Router                         │
│  ├── 滑点 > 1% 的交易                                │
│  └── 单笔 > 0.5 ETH                                  │
│                                                      │
│  🟡 必须人工确认：                                   │
│  ├── 单笔 > 0.1 ETH 且 ≤ 0.5 ETH                    │
│  ├── 新 Token 首次交易                               │
│  ├── 滑点 0.5% ~ 1%（边界情况）                      │
│  └── Gas Price > 50 Gwei（避免高 gas 成本）          │
│                                                      │
│  📊 执行后检查：                                     │
│  ├── 验证实际收到的 Token 数量 ≥ 预期 × (1 - 滑点)  │
│  ├── 记录交易哈希到审计日志                          │
│  └── 检查 MEV：是否被 sandwich attack                │
│      └── 方法：对比提交价格和实际成交价格的差异       │
│                                                      │
└──────────────────────────────────────────────────────┘
```

## 6. 关键学习点

| 概念 | 本交易中的体现 | Agent 风险 |
|------|---------------|------------|
| **滑点** | 0.49%，损失 12.37 USDC | 大额交易滑点会急剧增大 |
| **手续费** | LP Fee 0.3% + Gas Fee | 高 gas 时成本可能超过滑点 |
| **流动性深度** | 池子 $1.2 亿 TVL | 浅池子 = 高滑点 = 高风险 |
| **MEV** | 本交易未被 sandwich | Agent 交易容易被 MEV 机器人抢跑 |
| **路由** | 直连 WETH/USDC 池 | 多跳路由会增加 gas 和滑点 |
